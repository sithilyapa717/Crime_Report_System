# Screen font

`NotoSansSinhala-VF-unhinted.woff2` is Noto Sans Sinhala (variable, weights 100–900) from
`google/fonts` (`ofl/notosanssinhala`), with the width axis fixed at 100 and the TrueType hinting
removed. The hinted builds (Google Fonts, `@fontsource`) are snapped to the pixel grid on Windows
and look jagged at the app's 13–17px sizes; unhinted outlines render smooth. Licence: `OFL.txt`.

Print and Word output keep their own fonts (`packages/documents/print-layouts/fonts`).
